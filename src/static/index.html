You are using localhost, which only works on this computer. On other devices use this computer's network IP address (for example http://192.168.x.x:8000), printed in the server console when it starts.

How to use

  1. Open the Projector Display on the projector computer and press F11.
  2. Open Operator Control on your phone, tablet or laptop.
  3. Pick a song or slide, then click a line to show it on the projector.
